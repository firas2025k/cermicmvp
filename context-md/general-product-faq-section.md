# General product FAQ section (dashboard guide)

This is a **separate** FAQ block from the buy-box accordion (Description / FAQ / Care & Shipping). It shows feature icons, a lifestyle image, and a second FAQ accordion on the product page.

Content is edited once site-wide. Each product has an on/off switch.

---

## Where things live

| What | Where in admin |
| ---- | -------------- |
| Shared content (icons, image, FAQs) | **Globals → Product FAQ Section** |
| Show/hide on a product | Product → **Content** tab → **Show general FAQ section** |

Do **not** put this content in the product’s existing **FAQ Items** field — that still powers the buy-box accordion only.

---

## 1. Edit the shared section

1. Open admin → **Globals** → **Product FAQ Section**.
2. Fill in the fields below, then **Save**.

### Feature Icons

Up to 5 rows. Each row has:

- **Icon** — pick one of the built-in graphics (you cannot upload custom icons)
- **Label** — the text under the icon (editable)

Defaults are already seeded:

| Icon | Default label |
| ---- | ------------- |
| Knife-friendly | Messerfreundlich |
| Colorful grain | Farbenprächtig |
| Food-safe | Lebensmittelecht |
| Antibacterial | Antibakteriell |
| Easy care | Pflegeleicht |

Leave the array empty if you want to hide the icon row entirely.

### FAQ Heading

Title above the accordion (default: `FAQ'S`).

### FAQ Image

Upload a lifestyle / product image. Shown on the left of the accordion on desktop; stacked above it on mobile.

### FAQ Items

Add questions and rich-text answers. These appear in the accordion on the right.

Order in the dashboard = order on the site. The first item opens by default.

---

## 2. Turn it on for a product

1. Open the product in admin.
2. Go to the **Content** tab.
3. Enable **Show general FAQ section**.
4. **Save** / **Publish**.

With the checkbox off (default), the section does not appear on that product page — even if the Global has content.

---

## 3. What the customer sees

On a product page where the toggle is on, below the existing buy-box FAQ:

1. Row of feature icons + labels  
2. Image (left) + heading + FAQ accordion (right)

If icons, image, and FAQ items are all empty, nothing renders.

---

## Quick checklist

- [ ] Global content saved under **Product FAQ Section**
- [ ] Image uploaded (optional but recommended)
- [ ] At least one FAQ item added (optional if you only want icons)
- [ ] **Show general FAQ section** enabled on the product(s) that should show it
- [ ] Product published
