## Known pitfalls / do not redo

| Topic | Note |
|--------|------|
| New Payload collection | Always add `payload_locked_documents_rels.<slug>_id` (+ FK/index) in Neon SQL. |
| Invoice regenerate | Rebuild from snapshot; do **not** allocate a new number. File was once overwritten by mistake during analytics work — current file must stay the regenerate utility. |
| Vercel Blob | Out of scope for invoice recovery. |
| Seed flow | Destructive — never run against Neon with real data. |
| Analytics plugin | Nouance package incompatible with Payload 3.79. |
| Money display | Store cents; format with `formatEUR` in admin UI. |
